# @uplo/service-base

Shared base implementation used by Uplo storage services (e.g. [`@uplo/service-s3`](https://www.npmjs.com/package/@uplo/service-s3), [`@uplo/service-gcs`](https://www.npmjs.com/package/@uplo/service-gcs)).

This is an internal package — you don't need to install it directly. Use one of the concrete service packages instead.

## Documentation

See the full docs at [uplo.js.org](https://uplo.js.org).
