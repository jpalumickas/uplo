# @uplo/types

Shared TypeScript types used internally by [Uplo](https://uplo.js.org) packages.

This is an internal package — you don't need to install it directly. Use [`@uplo/server`](https://www.npmjs.com/package/@uplo/server) or [`@uplo/node`](https://www.npmjs.com/package/@uplo/node), which re-export the public types you'll need.

## Documentation

See the full docs at [uplo.js.org](https://uplo.js.org).
